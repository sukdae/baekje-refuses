# 백제 레퓌제 (가상 전시 · 시제품)

낙선전(Salon des Refusés)에서 이름을 빌린 백제 가상 전시. 웹 3D 3인칭으로 걷는다.

- 코스 1 · 백제문화관: 정읍사, 사택지적비, 금동대향로
- 코스 2 · 백제역사관: 한성의 끝부터 부흥운동까지 8막

설명은 사실·추정·상상·확인 중으로 나누어 적었다. 출처를 확인하지 못한 것은 '확인 중'으로 둔다.

## 3D 모형 (`models/`)

블렌더로 직접 만든 모형이다. 실측·복원 모델이 아니라 형상 표현이다.

- `sataek.glb` 사택지적비: 깨진 모양·크기·재질은 실측이 아님.
- `hyangno.glb` 금동대향로: 비율과 봉우리·꽃잎 수는 임의, 세부 장식은 넣지 않음.
- `jeongeup.glb` 정읍사: 유물이 아닌 노래이므로 노래 속 장면(기다리는 여인, 밤길)을 시각화. 실제 인물·옷차림의 재현이 아님.
- `purma.glb` 주인공: 영남대학교 마스코트 '푸르마'를 학교 허락을 받아 사용. 푸른 백제 관복 차림은 고증을 거치지 않은 표현이다.

모형은 `index.html`과 같은 폴더에서 웹 서버로 열어야 불러와진다. 파일을 직접 열면 간이 형상이 보인다.
